# isotropic-subspaces-for-skewforms
This is a computational approach to computing the function $d($**F**$, n, k)$ discussed in *Isotropic Subspaces for Skewforms and Maximal Abelian Subgroups of p-Groups*, Buhler, Gupta, Harris, 1987 ([read online](https://www.sciencedirect.com/science/article/pii/0021869387901384)).

## Definitions and Overview
Let **F** be a field, and let $n$ and $k$ be positive integers. Let $V$ be an $n$-dimensional vector space over **F** and $\alpha = {\alpha_1, ..., \alpha_k}$ be a collection of $k$ skewforms (i.e. alternating bilinear forms) on $V$. A subspace $W$ of $V$ is isotropic for $\alpha$ if it is isotropic for every $\alpha_i$. Let $m(\alpha)$ denote the dimension of the largest isotropic subspace for $\alpha$. Then $d($**F**$, n, k)$ is the minimum value of $m(\alpha)$ as $\alpha$ ranges over all collections of $k$ skewforms on $V$.
